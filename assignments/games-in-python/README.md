
# 📘 Assignment: Hangman Game

## 🎯 Objective

In this assignment, you will build a classic Hangman word-guessing game using Python. You'll practice essential programming skills including string manipulation, loops, conditionals, and random selection to create an interactive game that challenges players to guess a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Implement Hangman Game

#### Description
Create a complete Hangman game where players can guess letters to reveal a hidden word. The game should provide feedback on correct and incorrect guesses, track remaining attempts, and determine win or lose conditions.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses from the user and display current progress using underscores (_ _ _ format)
- Track the number of incorrect guesses remaining
- End the game when the word is fully guessed or when attempts are exhausted
- Display appropriate win or lose messages at the end
